# 🌍 AbroadDream – University Counselling Website Prototype

## 📌 Project Overview

AbroadDream is a UI/UX prototype designed using **Axure RP** for a university counselling and scholarship searching platform. This project was developed as part of a UI/UX engineering exercise.

The system is designed to help students explore 🎓 universities, 📚 courses, 💰 scholarships, and study opportunities in countries such as Australia, Canada, USA, and UK.

The prototype focuses on improving user experience by applying UI/UX design principles, interactive navigation, and a clean, user-friendly interface.

---

## 🎯 Project Objectives

* 🎨 Design a user-friendly university search system
* 🧠 Apply UI/UX design principles
* 🖥️ Create an interactive prototype using Axure RP
* 🚀 Improve usability and user experience

---

## ⭐ Key Features

### 🏠 Home Page

* 🔐 Register & Login
* 🔍 Search functionality
* 📞 Help & Contact
* 🔔 Notifications
* ℹ️ About Us
* 👤 User Profile

---

### 📝 User Registration

Users can register using:

* 👤 Full Name
* 🎂 Date of Birth
* ⚧ Gender
* 🏠 Address
* 🌍 Country
* 📱 Mobile Number
* 📧 Email
* 🔑 Password

---

### 🔐 Login System

* Validates **email & password**
* Only registered users can access the system

---

### 👤 Profile Page

* Displays all user registration details after login

---

### 🎓 University Search

Users can filter universities by:

* 🌍 Country
* 📚 Field of Study
* 🎓 Degree Type
* 🕒 Attendance Type

---

### 📋 University Results

Each result displays:

* 🏫 University Name
* 📖 Course Name
* 💰 Annual Fees
* 📍 Location
* 🔘 “View Details” button (redirects to official university website)

---
